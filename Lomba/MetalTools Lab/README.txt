METALTOOLS LAB
Paket ZIP Offline
================

Deskripsi
---------
MetalTools Lab adalah simulasi pembelajaran interaktif mengenai peralatan dan
proses kerja logam yang dapat digunakan secara offline.

Informasi Pembuat
-----------------
Nama pembuat : MetalTools Lab
Format       : SPA (Single Page Application) Offline
Rasio desain : 16:9

Simulasi ini dirancang sesuai ketentuan rasio tampilan 16:9 dan dikemas sebagai
SPA Offline agar seluruh pengalaman dapat dijalankan tanpa koneksi internet.

Cara Membuka
------------
1. Ekstrak file ZIP ke folder pilihan Anda.
2. Buka folder hasil ekstraksi.
3. Klik dua kali file `index.html` untuk menjalankan aplikasi di browser.

Peringatan
----------
Simulasi ini hanya untuk pembelajaran dan demonstrasi. Simulasi tidak
menggantikan praktik bengkel asli, pelatihan keselamatan kerja, pengawasan
instruktur, maupun penggunaan alat dan prosedur yang sesuai standar.
